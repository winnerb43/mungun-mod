Өөрийн cloud нөөц

Ахисан түвшний, заавал биш боломж

Апп нөөц файлыг таны оруулсан нууц үгээр утсан дээр шифрлээд, таны өөрийн Supabase төсөл рүү илгээж чадна. Сервер нь таных бөгөөд зөвхөн шифрлэгдсэн файл хадгална. Бид тэр серверт хандах эрхгүй.

Энгийн хэрэглээнд Тохиргоо → "Нөөцлөх ба сэргээх" хэсгийн нөөц файл хангалттай. Доорх тохиргоог компьютер дээрээс хийхэд 10 орчим минут зарцуулна.

Тохируулах алхам

  1. supabase.com дээр бүртгүүлж, шинэ төсөл (New project) үүсгэнэ. Өөр зорилгоор ашигладаг төслөөсөө тусад нь үүсгээрэй.
  2. Төслийн SQL Editor-т доорх SQL-ийг бүхэлд нь хуулж тавиад Run дарна. Энэ нь хувийн "backups" сан үүсгэж, нэвтэрсэн хэрэглэгч зөвхөн өөрийн хавтсыг унших, бичих, устгах дүрэм тогтооно.
  3. Authentication → Sign In / Providers хэсэгт "Allow new users to sign up"-ийг унтраана.
  4. Authentication → Users → Add user: и-мэйл, нууц үгээ оруулж (Auto Confirm) хэрэглэгч үүсгэнэ.
  5. Project Settings → API хэсгээс Project URL болон anon (publishable) key-г хуулж, апп-ын Тохиргоо → "Нөөцлөх ба сэргээх" → "Өөрийн cloud нөөц" дэлгэцэд 4-р алхмын и-мэйл, нууц үгтэй хамт оруулна.

SQL

-- 1. Хувийн сан (bucket)
insert into storage.buckets (id, name, public)
values ('backups', 'backups', false)
on conflict (id) do nothing;

-- 2. Зөвхөн өөрийн хавтас (эхний хавтас = auth.uid())
create policy "backups: own read" on storage.objects
  for select to authenticated
  using (bucket_id = 'backups' and (storage.foldername(name))[1] = (select auth.uid())::text);

create policy "backups: own insert" on storage.objects
  for insert to authenticated
  with check (bucket_id = 'backups' and (storage.foldername(name))[1] = (select auth.uid())::text);

create policy "backups: own delete" on storage.objects
  for delete to authenticated
  using (bucket_id = 'backups' and (storage.foldername(name))[1] = (select auth.uid())::text);

Мэдэх зүйлс

  • Нөөцийн нууц үгээ мартвал файлыг сэргээх боломжгүй. Найдвартай газар хадгална уу.
  • Апп Supabase-ийн нууц үгийг хадгалдаггүй, зөвхөн нэвтрэлтийн токенийг утасны хамгаалагдсан санд хадгална.
  • Сүүлийн 10 нөөц хадгалагдаж, хуучин нь автоматаар устна.
  • Supabase-ийн үнэгүй төсөл 7 хоног ашиглагдахгүй бол түр зогсдог. Апп-ын "Автомат нөөц"-ийг асаавал өдөр бүр нөөцөлж, төслийг идэвхтэй байлгана.
